# Local Font Awesome icons

This directory keeps the small set of Font Awesome Free icons used by the app without installing the Font Awesome npm packages. All icons inherit their visible color from the `fill` attribute in the SVG file and can be used with a root-relative path, for example `/icons/font-awesome/gear.svg`.

## Included icons

- Travel editor: `plus`, `minus`, `circle-solid`, `circle-regular`, `pen-to-square`, `circle-minus`
- UI: `arrow-left`, `arrow-right`, `arrow-up`, `arrow-down`, `check`, `xmark`, `gear`, `trash-can`
- Game: `house`, `map`, `shield`, `users`, `coins`, `heart`, `star`

The icon artwork is covered by the attribution notice in `LICENSE.txt`.
